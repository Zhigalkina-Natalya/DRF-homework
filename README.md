# Django LMS Project — Часть 1

Учебный проект по разработке **LMS (Learning Management System)** — платформы для онлайн-обучения, где пользователи могут размещать свои курсы и уроки.

Проект реализован с использованием **Django** и **Django REST Framework**.  
Результат — это **backend-сервер**, возвращающий клиенту JSON-ответы.

---

## Задание

**Цель:** разработать базу для LMS-системы с моделями пользователей, курсов и уроков, а также реализовать CRUD для них.

### Основные задачи:
1. Создать Django-проект и подключить **DRF**.  
2. Реализовать модели:
   - **Пользователь** (авторизация по email, с доп. полями);
   - **Курс**;
   - **Урок** (связь с курсом).
3. Реализовать **CRUD**:
   - Для курса — через `ViewSet`;
   - Для урока — через `GenericAPIView`.
4. Проверить работу эндпоинтов через **Postman**.

### Дополнительное задание:
Создать эндпоинт для редактирования профиля пользователя (через `ViewSet` или `Generic`).

# Django LMS Project — Часть 2

**Продолжение проекта LMS** — расширение функционала бэкенда.

### Основные изменения:
1. Поле `lessons_count`

Добавлено в сериализатор курса с помощью SerializerMethodField().
Теперь курс выводит количество уроков и их список одновременно.

2. Модель `Payment`

Создана в приложении users, содержит поля:
- user, paid_at, course, lesson, amount, payment_method.
- Способы оплаты: cash (наличные) и transfer (перевод).
- Данные можно загрузить через команду: `python manage.py create_sample_payments`

3. Фильтрация и сортировка платежей

Эндпоинт /users/payments/ поддерживает:
- фильтр по course, lesson, payment_method;
- сортировку по paid_at.

4. История платежей пользователя

В сериализаторе профиля добавлено поле payments.
Эндпоинт /users/<id>/ теперь возвращает список платежей конкретного пользователя.

### Примеры запросов (Postman)

`GET` `/materials/courses/1/`
→ возвращает курс с полями lessons_count и lessons.

`GET` `/users/payments/?payment_method=transfer`
→ фильтрация по способу оплаты.

`GET` `/users/1/`
→ профиль пользователя с историей платежей.
